#+TITLE: rx-query-replace
#+AUTHOR: Kazure Zheng

* rx-query-replace

用 =rx= 宏编写正则，实时预览匹配结果，输入 replacement 时实时预览替换结果，交互式替换。

两个命令：

- =M-x rx-query-replace= ：确认后对每个匹配 y/n 询问（query replace）
- =M-x rx-replace= ：确认后一次替换全部匹配（replace all）

#+begin_src text
M-x rx-query-replace
        │
        ▼
┌────────────────────────────┐
│ '(seq                      │
│    "TODO"                  │
│    (+ blank)               │
│    (group (+ nonl)))       │
└────────────────────────────┘
        │
实时高亮
        │
        ▼
C-c C-c
        │
输入 replacement
（每敲一键，所有匹配实时显示替换结果）
        │
        ▼
RET 确认
        │
        ▼
y/n 逐个确认（rx-replace 跳过此步）
        │
        ▼
替换完成 → RE-Builder 窗口自动关闭
#+end_src

整个过程都不需要写传统 regexp。

* 为什么做

传统工作流需要三个步骤：

#+begin_src text
re-builder
      │
      ▼
验证 regexp
      │
C-c C-w
      ▼
复制 regexp
      │
query-replace-regexp
      │
C-y
      ▼
输入 replacement
#+end_src

需要两个命令、一个 kill-ring、一个中间字符串；而且输入 replacement 时看不到任何替换效果，错了要重来。本包把这些合并成一个命令，并给 replacement 输入加上实时预览（参考 visual-regexp 的 =vr/replace= / =vr/query-replace=）。

* 安装

#+begin_src elisp
(add-to-list 'load-path "/path/to/rx-replace")
(require 'rx-query-replace)
#+end_src

或 use-package：

#+begin_src elisp
(use-package rx-query-replace
  :load-path "/path/to/rx-replace")
#+end_src

依赖：Emacs ≥ 28.1（使用 =re-builder= 的 rx 语法相关内部函数，已验证 30.2）。

* 用法

1. 在想要替换的 buffer 中运行 =M-x rx-query-replace= 或 =M-x rx-replace=。该 buffer 成为替换目标，另一个窗口打开 =*RE-Builder*= buffer，内容为 ='(seq)=。
2. 在其中编辑 rx 表达式，例如 ='(seq "TODO" (+ blank) (group (+ nonl)))=。每次编辑都会在目标 buffer 中实时高亮所有匹配；无效的 rx 只在 mode-line 报错，不会崩溃。
3. =C-c C-c=：minibuffer 输入 replacement（支持 =\1= 等分组引用）。*每敲一键，所有匹配位置实时显示替换结果*（overlay 虚拟预览，此时目标 buffer 内容并未真正修改）。
   - =RET= / =C-c C-c= 确认：=rx-query-replace= 进入 y/n 逐个确认；=rx-replace= 直接替换全部。完成（含 y/n 循环结束）后 RE-Builder 窗口自动关闭。
   - =C-g= / =C-c C-k= 取消：只移除预览，回到 rx buffer 继续编辑。
4. =C-c C-r=：随时以「替换全部」语义执行（与入口命令无关）。
5. =C-c C-k=（在 rx buffer 中）：直接退出，删高亮、恢复窗口配置和 re-builder 语法设置。

rx buffer 内的键：

| 键 | 命令 | 说明 |
|-----------+--------------------------------+--------------------------------------------|
| =C-c C-c= | =rx-query-replace-submit= | 输入 replacement（实时预览），按入口语义替换 |
| =C-c C-r= | =rx-query-replace-submit-all= | 同上，但直接替换全部，不逐个确认 |
| =C-c C-k= | =rx-query-replace-quit= | 退出 |
| =C-c C-t= | =reb-toggle-case= | 切换大小写敏感（原 re-builder 的 C-c C-c） |
| =C-c C-w= | =reb-copy= | 复制编译后的 regexp 到 kill-ring |
| =C-c C-s= | =reb-next-match= | 跳转到下一个匹配（prev-match 被 C-c C-r 遮蔽，可用菜单） |
| =C-c C-u= | =reb-force-update= | 忽略匹配上限强制刷新 |
| =C-c C-q= | =reb-quit= | re-builder 原生退出 |

从任意 buffer 再次运行 =M-x rx-query-replace= 会把该 buffer 设为新的替换目标；对同一目标 buffer 重进会自动恢复上次的 rx 表达式。

大小写：高亮预览与替换都遵循目标 buffer 的 =case-fold-search=（默认开启，=C-c C-t= 切换）。与 =query-replace-regexp= 不同，regexp 中出现大写字母不会让替换悄悄切换成大小写敏感——所见即所替。

* 实现原理

本包是 =re-builder= 的一个薄层（约 300 行），没有自己画匹配高亮、没有自己解析 rx：

- **rx 编辑**：将 =reb-re-syntax= 设为 =rx= 后进入 =re-builder=，其 =*RE-Builder*= buffer 使用 =reb-lisp-mode=（派生自 =emacs-lisp-mode=，免费获得缩进、paredit/smartparens/tree-sitter/rainbow-delimiters 支持），并自带 rx 关键字高亮。
- **编译**：=reb-cook-regexp= 内部即 =(rx-to-string (eval (car (read-from-string re))))=，编辑的 rx 形式被实时编译为 regexp 字符串。
- **匹配实时高亮**：复用 =reb-auto-update=（挂在 =after-change-functions=）→ =reb-update-regexp= → =reb-update-overlays=，分组多色 overlay、200 匹配上限、无效表达式只在 mode-line 报错全部现成。
- **替换实时预览**（参考 visual-regexp）：=C-c C-c= 后 minibuffer 读取 replacement，每次按键经 =after-change-functions= 触发 =rx-query-replace--update-preview=——对每个匹配创建 overlay，用 =display= 属性虚拟显示 =match-substitute-replacement= 计算出的替换文本（支持 =\N=、case 保留），*不修改目标 buffer*；确认（RET）后才真正替换，取消（C-g）零成本。
- **替换执行**：=rx-query-replace= 用 =perform-replace=（与 =query-replace-regexp= 完全一致），并绑定 =search-upper-case= 为 nil 以保持与预览一致的大小写语义；=rx-replace= 用逐匹配 =replace-match= 循环。两者都遵循提交时捕获的 region 限制。
- **键位冲突**：=reb-mode-map= 中 =C-c C-c= 原本是 =reb-toggle-case=，本包的 minor-mode keymap（minor 优先于 major）覆盖了它，并把 toggle-case 挪到 =C-c C-t=。

* 限制

- 依赖 =re-builder= 的私有 API（=reb-*=），最低 Emacs 28.1，不保证未来版本不破坏；本包升级前可对照 =re-builder.el= 源码。
- 匹配高亮与替换预览最多处理 =reb-auto-match-limit=（默认 200）个匹配，超出部分不显示（可用 =C-c C-u= 强制刷新查看全部高亮）。
- 替换预览期间的错误提示（如无效的 =\N= 引用）显示在 minibuffer，直到下一次按键。
- 替换期间若把目标 buffer 杀掉会报错（未处理）。
- 空匹配的正则（如默认的 ='(seq)=）可以替换，行为与 =query-replace-regexp= 一致。
- rx 形式会被 =eval=（re-builder rx 语法的既有行为），请不要在表达式中写有副作用的 Lisp 代码。

* 路线图

- 第二版剩余：=C-c C-e= 导出 regexp 到 kill-ring。（=C-c C-r= 直接替换已交付，并升级为带实时预览的 =rx-replace=）
- 第三版：rx / replacement 历史，=M-p= 浏览。
- 第四版：replace-string 风格，自动生成 =(rx "foo")=。
- 第五版：多 buffer（=project-query-replace=，=consult-ripgrep= 集成）。
- 第六版：作为 =re-builder= 的扩展命令（=C-c C-q= 变成 "Query Replace"）。
- 更远：=rx-isearch=、=rx-occur=、=rx-export-regexp=、=rx-describe=、=regexp-to-rx= 等完整 rx 工具集。
