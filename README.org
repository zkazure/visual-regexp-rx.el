#+AUTHOR: Kazure Zheng

* visual-regexp-rx

=visual-regexp= 的 =rx= 引擎扩展——如同 =visual-regexp-steroids= 之于 PCRE。在 minibuffer 里直接输入 =rx= 形式的 Lisp 结构代替 regexp 字符串，其余（实时预览、y/n 确认、全部 minibuffer 快捷键）都是 visual-regexp 原生体验。

#+begin_src text
M-x vr/query-replace
        │
        ▼
Query replace regexp: (seq "TODO" (+ blank) (group (+ nonl)))
        │
        ▼
输入 replacement
（每敲一键，每个匹配后实时显示 → 替换结果）
        │
        ▼
RET 确认 → y/n 逐个确认（vr/replace 跳过此步）
#+end_src

* 用法

在 init.el 里选择引擎（一次性配置）：

#+begin_src elisp
(setq vr/engine 'rx)
#+end_src

之后直接使用原版 visual-regexp 命令：

- =M-x vr/query-replace= ：每个匹配 y/n 逐个确认（query replace）
- =M-x vr/replace= ：一次替换全部匹配

改回 =(setq vr/engine 'emacs)= 即恢复普通 regexp 行为。

minibuffer 打开时预填 =(seq "")= 且光标停在双引号中间，直接打字即可；输入裸 list（无需 quote）：=(seq "TODO" (+ blank) (group (+ nonl)))=，按 =read= 解析后交给 =rx-to-string= 编译。输入不是合法 rx form 时按 visual-regexp 的既有方式报 =invalid-regexp=；空 =()= 占位在输入过程中自动视为 =(seq)=，保证高亮不中断。

minibuffer 快捷键（visual-regexp 原生，未做任何改动）：

| 键 | 命令 | 说明 |
|-----------+------------------------------+------------------------------------------------|
| =RET= | =exit-minibuffer= | 确认 replacement |
| =C-g= | =keyboard-quit= | 取消 |
| =C-c p= | =vr--shortcut-toggle-preview= | 切换预览样式：箭头（匹配 → 替换）/ 直接显示替换结果 |
| =C-c a= | =vr--shortcut-toggle-limit= | 切换显示上限（默认 50 / 全部匹配） |
| =C-c ?= | =vr--minibuffer-help= | 帮助 |
| =M-p= / =M-n= | history | 浏览 replacement 历史 |

* 为什么做

传统 =query-replace-regexp= 需要先写好、验证好 regexp 字符串再开始替换，且输入 replacement 时看不到任何效果。visual-regexp 解决了预览问题，但仍是 regexp 字符串语法（Emacs 风格反斜杠地狱）。=rx= 形式可读、可缩进、可注释，本包把两者合并：rx 的可读性 + visual-regexp 的实时预览。

* 安装

本包依赖 [[https://github.com/benma/visual-regexp.el][visual-regexp]] ≥ 1.1：

#+begin_src elisp
;; visual-regexp（若尚未安装）
(add-to-list 'load-path "/path/to/visual-regexp")
(require 'visual-regexp)

;; 本包
(add-to-list 'load-path "/path/to/visual-regexp-rx")
(require 'visual-regexp-rx)
#+end_src

或 use-package：

#+begin_src elisp
(use-package visual-regexp
  :load-path "/path/to/visual-regexp")

(use-package visual-regexp-rx
  :load-path "/path/to/visual-regexp-rx")
#+end_src

依赖：Emacs ≥ 28.1；visual-regexp ≥ 1.1。

* 与 visual-regexp-steroids 共存

引擎开关共用 =vr/engine=：未安装 steroids 时本包定义它（=emacs= / =rx=）；已安装时本包把 =rx= 加入其引擎选项。两包同时加载时引擎选择互不干扰。

* 实现原理

一条 around advice、一个预填 hook（约 100 行）：

- =advice-add 'vr--get-regexp-string :around= ：在 visual-regexp 拿到 minibuffer 输入之后、编译使用之前，当 =vr/engine= 为 =rx= 时把输入 =read= 为 Lisp 结构并交给 =rx-to-string=；空 =()= 占位先递归替换为 =(seq)=。
- =for-display= 为 t 的调用（仅显示用途）不转换，保持用户输入的 rx 原文。
- =minibuffer-setup-hook= ：=rx= 引擎下 regexp 输入预填 =(seq "")= 且光标停在双引号中间。
- 转换错误转成 =invalid-regexp=，由 visual-regexp 的既有错误显示处理。
- 本包不定义任何命令——引擎开关即全部接口，命令仍是 =vr/query-replace= / =vr/replace=。

* 限制

- 依赖 visual-regexp 私有 API =vr--get-regexp-string=（已验证 1.1，未来版本需对照源码）。
- =vr/engine= 与 visual-regexp-steroids 共享符号；若 steroids 后加载会重定义该变量并覆盖 choice 列表（=rx= 仍可通过 =setq= 使用）。
- rx form 在 minibuffer 一行书写，复杂多行结构建议先在 scratch buffer 里构造再粘贴。
- rx form 经 =read= + =rx-to-string=，不要在其中写有副作用的代码。
