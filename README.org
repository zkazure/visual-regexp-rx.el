#+TITLE: rx-query-replace
#+AUTHOR: Kazure Zheng

* rx-query-replace

用 =rx= 宏编写正则，实时预览匹配结果，并直接进行交互式替换。

#+begin_src text
M-x rx-query-replace
        │
        ▼
┌────────────────────────────┐
│ '(seq                      │
│    "TODO"                  │
│    (+ blank)               │
│    (group (+ nonl)))       │
└────────────────────────────┘
        │
实时高亮
        │
        ▼
C-c C-c
        │
输入 replacement
        │
        ▼
query replace
#+end_src

整个过程都不需要写传统 regexp。

* 为什么做

传统工作流需要三个步骤：

#+begin_src text
re-builder
      │
      ▼
验证 regexp
      │
C-c C-w
      ▼
复制 regexp
      │
query-replace-regexp
      │
C-y
      ▼
输入 replacement
#+end_src

需要两个命令、一个 kill-ring、一个中间字符串；理想流程只有一个命令，即本包提供的 =rx-query-replace=。

* 安装

#+begin_src elisp
(add-to-list 'load-path "/path/to/rx-replace")
(require 'rx-query-replace)
#+end_src

或 use-package：

#+begin_src elisp
(use-package rx-query-replace
  :load-path "/path/to/rx-replace")
#+end_src

依赖：Emacs ≥ 28.1（使用 =re-builder= 的 rx 语法相关内部函数，已验证 30.2）。

* 用法

1. 在想要替换的 buffer 中运行 =M-x rx-query-replace=。该 buffer 成为替换目标，另一个窗口打开 =*RE-Builder*= buffer，内容为 ='(seq)=。
2. 在其中编辑 rx 表达式，例如 ='(seq "TODO" (+ blank) (group (+ nonl)))=。每次编辑都会在目标 buffer 中实时高亮所有匹配；无效的 rx 只在 mode-line 报错，不会崩溃。
3. =C-c C-c=：读取 replacement（支持 =\1= 等分组引用），然后对目标 buffer 执行交互式替换（每次命中询问 y/n）。替换结束后回到 rx buffer，可继续修改 rx 再次替换。
4. =C-c C-k=：取消。删除高亮、bury buffer、恢复窗口配置和 re-builder 语法设置。

| 键 | 命令 | 说明 |
|-----------+----------------------------+----------------------------------------|
| =C-c C-c= | =rx-query-replace-submit= | 读取 replacement 并开始 query-replace |
| =C-c C-k= | =rx-query-replace-quit= | 取消并退出 |
| =C-c C-t= | =reb-toggle-case= | 切换大小写敏感（原 re-builder 的 C-c C-c） |
| =C-c C-w= | =reb-copy= | 复制编译后的 regexp 到 kill-ring |
| =C-c C-s= / =C-c C-r= | =reb-next-match= / =reb-prev-match= | 跳转到下一个/上一个匹配 |
| =C-c C-u= | =reb-force-update= | 忽略匹配上限强制刷新 |
| =C-c C-q= | =reb-quit= | re-builder 原生退出 |

从任意 buffer 再次运行 =M-x rx-query-replace= 会把该 buffer 设为新的替换目标；对同一目标 buffer 重进会自动恢复上次的 rx 表达式。

* 实现原理

本包是 =re-builder= 的一个薄层（约 150 行），没有自己画 overlay、没有自己解析 rx：

- **rx 编辑**：将 =reb-re-syntax= 设为 =rx= 后进入 =re-builder=，其 =*RE-Builder*= buffer 使用 =reb-lisp-mode=（派生自 =emacs-lisp-mode=，免费获得缩进、paredit/smartparens/tree-sitter/rainbow-delimiters 支持），并自带 rx 关键字高亮。
- **编译**：=reb-cook-regexp= 内部即 =(rx-to-string (eval (car (read-from-string re))))=，编辑的 rx 形式被实时编译为 regexp 字符串。
- **实时预览**：复用 =reb-auto-update=（挂在 =after-change-functions=）→ =reb-update-regexp= → =reb-update-overlays=，提供分组多色 overlay 高亮、200 匹配上限、无效表达式只在 mode-line 报错等全部现成行为。
- **替换**：=C-c C-c= 读取 replacement 后调用 =perform-replace=，与 =query-replace-regexp= 完全一致；替换从目标 buffer 开头开始（与预览一致），若目标 buffer 有活动 region 则仍只替换 region。替换结束后强制刷新高亮。
- **键位冲突**：=reb-mode-map= 中 =C-c C-c= 原本是 =reb-toggle-case=，本包的 minor-mode keymap（minor 优先于 major）覆盖了它，并把 toggle-case 挪到 =C-c C-t=。

* 限制

- 依赖 =re-builder= 的私有 API（=reb-*=），最低 Emacs 28.1，不保证未来版本不破坏；本包升级前可对照 =re-builder.el= 源码。
- 预览最多高亮 =reb-auto-match-limit=（默认 200）个匹配，超出部分不显示（可用 =C-c C-u= 强制刷新查看全部）。
- 替换期间若把目标 buffer 杀掉会报错（未处理）。
- 空匹配的正则（如默认的 ='(seq)=）可以替换，行为与 =query-replace-regexp= 一致。
- rx 形式会被 =eval=（re-builder rx 语法的既有行为），请不要在表达式中写有副作用的 Lisp 代码。

* 路线图

- 第二版：=C-c C-e= 导出 regexp 到 kill-ring；=C-c C-r= 直接 =replace-regexp=（不询问）。
- 第三版：rx / replacement 历史，=M-p= 浏览。
- 第四版：replace-string 风格，自动生成 =(rx "foo")=。
- 第五版：多 buffer（=project-query-replace=，=consult-ripgrep= 集成）。
- 第六版：作为 =re-builder= 的扩展命令（=C-c C-q= 变成 "Query Replace"）。
- 更远：=rx-isearch=、=rx-occur=、=rx-export-regexp=、=rx-describe=、=regexp-to-rx= 等完整 rx 工具集。
