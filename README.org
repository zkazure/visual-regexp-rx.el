#+TITLE: rxr
#+AUTHOR: Kazure Zheng

* rxr

用 =rx= 宏编写正则，实时预览匹配结果，输入 replacement 时实时预览替换结果（箭头样式），交互式替换。

两个命令：

- =M-x rxr-query-replace= ：确认后对每个匹配 y/n 询问（query replace）
- =M-x rxr-replace= ：确认后一次替换全部匹配（replace all）

#+begin_src text
M-x rxr-query-replace
        │
        ▼
┌────────────────────────────┐
│ '(seq                      │
│    "TODO"                  │
│    (+ blank)               │
│    (group (+ nonl)))       │
└────────────────────────────┘
        │
实时高亮
        │
        ▼
C-c C-c
        │
输入 replacement
（每敲一键，每个匹配后实时显示 → 替换结果）
        │
        ▼
RET 确认
        │
        ▼
y/n 逐个确认（rxr-replace 跳过此步）
        │
        ▼
替换完成 → RE-Builder 窗口自动关闭
#+end_src

整个过程都不需要写传统 regexp。

* 为什么做

传统工作流需要三个步骤：

#+begin_src text
re-builder
      │
      ▼
验证 regexp
      │
C-c C-w
      ▼
复制 regexp
      │
query-replace-regexp
      │
C-y
      ▼
输入 replacement
#+end_src

需要两个命令、一个 kill-ring、一个中间字符串；而且输入 replacement 时看不到任何替换效果，错了要重来。本包把这些合并成一个命令，replacement 输入阶段的实时预览由 visual-regexp 驱动（=vr/replace= / =vr/query-replace= 同款体验）。

* 安装

本包依赖 [[https://github.com/benma/visual-regexp.el][visual-regexp]] ≥ 1.1：

#+begin_src elisp
;; visual-regexp（若尚未安装）
(add-to-list 'load-path "/path/to/visual-regexp")
(require 'visual-regexp)

;; 本包
(add-to-list 'load-path "/path/to/rxr")
(require 'rxr)
#+end_src

或 use-package：

#+begin_src elisp
(use-package visual-regexp
  :load-path "/path/to/visual-regexp")

(use-package rxr
  :load-path "/path/to/rxr")
#+end_src

依赖：Emacs ≥ 28.1（使用 =re-builder= 的 rx 语法相关内部函数，已验证 30.2）；visual-regexp ≥ 1.1。

* 用法

1. 在想要替换的 buffer 中运行 =M-x rxr-query-replace= 或 =M-x rxr-replace=。该 buffer 成为替换目标，另一个窗口打开 =*RE-Builder*= buffer，内容为 ='(seq)=。
2. 在其中编辑 rx 表达式，例如 ='(seq "TODO" (+ blank) (group (+ nonl)))=。每次编辑都会在目标 buffer 中实时高亮所有匹配。
   - *输入容错*：输入过程中未闭合的括号会自动补全（最多 =rxr-max-paren-recovery= 个，默认 20）参与编译；空 =()= 视为 =(seq)= 占位。因此高亮在输入过程中不会消失。
   - 真正的错误（如未知符号 ='(foo)=）照常在 mode-line 报错，不会崩溃。
3. =C-c C-c=：minibuffer 输入 replacement（支持 =\1= 等分组引用）。*每敲一键，每个匹配后实时显示「 → 替换结果」*（overlay 虚拟预览，目标 buffer 内容并未真正修改）。匹配保持 vr 高亮色，替换预览使用独立的 =rxr-replacement= face（浅绿背景，可用 =M-x customize-face= 调整），两者易于区分；纯 visual-regexp 会话不受影响。
   - =RET= 确认：=rxr= 进入 y/n 逐个确认（每个匹配同样带实时预览）；=rxr-replace= 直接替换全部。完成（含 y/n 循环结束）后 RE-Builder 窗口自动关闭。
   - =C-g= 取消：只移除预览，回到 rx buffer 继续编辑。
4. =C-c C-r=：随时以「替换全部」语义执行（与入口命令无关）。
5. =C-c C-k=（在 rx buffer 中）：直接退出，删高亮、恢复窗口配置和 re-builder 语法设置。

*rx buffer（RE-Builder）内的键*：

| 键 | 命令 | 说明 |
|-----------+--------------------------------+--------------------------------------------|
| =C-c C-c= | =rxr-submit= | 输入 replacement（实时预览），按入口语义替换 |
| =C-c C-r= | =rxr-submit-all= | 同上，但直接替换全部，不逐个确认 |
| =C-c C-k= | =rxr-quit= | 退出 |
| =C-c C-t= | =reb-toggle-case= | 切换大小写敏感（原 re-builder 的 C-c C-c） |
| =C-c C-w= | =reb-copy= | 复制编译后的 regexp 到 kill-ring |
| =C-c C-s= | =reb-next-match= | 跳转到下一个匹配 |
| =C-c C-u= | =reb-force-update= | 忽略匹配上限强制刷新 |

*minibuffer 内的键*（visual-regexp 原生，未做任何改动）：

| 键 | 命令 | 说明 |
|-----------+------------------------------+------------------------------------------------|
| =RET= | =exit-minibuffer= | 确认 replacement |
| =C-g= | =keyboard-quit= | 取消，回到 rx buffer |
| =C-c p= | =vr--shortcut-toggle-preview= | 切换预览样式：箭头（匹配 → 替换）/ 直接显示替换结果 |
| =C-c a= | =vr--shortcut-toggle-limit= | 切换显示上限（默认 50 / 全部匹配） |
| =C-c ?= | =vr--minibuffer-help= | 帮助 |
| =M-p= / =M-n= | history | 浏览 replacement 历史（=query-replace-to-history=） |

从任意 buffer 再次运行 =M-x rxr-query-replace= 会把该 buffer 设为新的替换目标；对同一目标 buffer 重进会自动恢复上次的 rx 表达式。

大小写：高亮预览与替换都遵循目标 buffer 的 =case-fold-search=（默认开启，=C-c C-t= 切换）。与 =query-replace-regexp= 不同，regexp 中出现大写字母不会让替换悄悄切换成大小写敏感——所见即所替。

* 实现原理

本包是 =re-builder= 与 visual-regexp 的薄层（约 270 行）：

- **rx 编辑**：将 =reb-re-syntax= 设为 =rx= 后进入 =re-builder=，其 =*RE-Builder*= buffer 使用 =reb-lisp-mode=（派生自 =emacs-lisp-mode=，免费获得缩进、paredit/smartparens/tree-sitter/rainbow-delimiters 支持），并自带 rx 关键字高亮。
- **编译**：=reb-cook-regexp= 内部即 =(rx-to-string (eval (car (read-from-string re))))=，编辑的 rx 形式被实时编译为 regexp 字符串。
- **匹配实时高亮**：复用 =reb-auto-update= → =reb-update-regexp= → =reb-update-overlays=，分组多色 overlay、200 匹配上限、无效表达式 mode-line 报错全部现成。
- **输入容错**：=reb-cook-regexp= 的 :around advice——parse 失败时自动补右括号重试；把空 =()= 递归替换为 =(seq)=。对合法 form 恒等，不改变任何正确语义。
- **替换实时预览与执行**：完全驱动 visual-regexp 内部机制——预设 =vr--regexp-string= / =vr--target-buffer= / bounds 后调用 =vr--set-replace-string= 读 replacement（minibuffer =after-change-functions= + overlay 箭头预览），确认后 =vr--do-replace=（全量）或 =vr--perform-query-replace=（逐匹配预览 y/n）。整个 vr 阶段绑定 =search-upper-case= 为 nil，保持「大小写跟随预览」语义；:around advice 给预览文字换上独立 face，并在会话结束清扫 vr hash 表里的预览 overlay（vr 自身只清理 visible-list）。
- **键位冲突**：=reb-mode-map= 中 =C-c C-c= 原本是 =reb-toggle-case=，本包的 minor-mode keymap（minor 优先于 major）覆盖了它，并把 toggle-case 挪到 =C-c C-t=。

* 限制

- 依赖两个第三方私有 API：=re-builder= 的 =reb-*= 函数与 visual-regexp 的 =vr--*= 函数（已验证 1.1，未来版本需对照 =re-builder.el= / =visual-regexp.el= 源码）。
- 匹配高亮最多 =reb-auto-match-limit=（默认 200）个；替换预览最多 =vr/default-feedback-limit=（默认 50）个，minibuffer 内 =C-c a= 切换全部。
- 输入容错 advice 对 =reb-cook-regexp= 全局生效（load 后对普通 re-builder 的 rx 语法同样起效，属增强）。
- 替换期间若把目标 buffer 杀掉会报错（未处理）。
- 空匹配的正则（如默认的 ='(seq)=）可以替换，行为与 =query-replace-regexp= 一致。
- rx 形式会被 =eval=（re-builder rx 语法的既有行为），请不要在表达式中写有副作用的 Lisp 代码。

* 路线图

- 第二版剩余：=C-c C-e= 导出 regexp 到 kill-ring。（=C-c C-r= 直接替换已交付，并升级为带实时预览的 =rxr-replace=）
- 第三版：历史已部分达成（vr 的 =query-replace-to-history= + =M-p=）；rx 表达式历史待做。
- 第四版：replace-string 风格，自动生成 =(rx "foo")=。
- 第五版：多 buffer（=project-query-replace=，=consult-ripgrep= 集成）。
- 第六版：作为 =re-builder= 的扩展命令（=C-c C-q= 变成 "Query Replace"）。
- 更远：=rx-isearch=、=rx-occur=、=rx-export-regexp=、=rx-describe=、=regexp-to-rx= 等完整 rx 工具集。
